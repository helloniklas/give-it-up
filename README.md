# I promise — website

The public pages for the **I promise** iOS app (project name Give It Up),
served by GitHub Pages from the root of this repository's `main` branch.

| Page | Purpose |
| --- | --- |
| [`index.html`](index.html) | Landing page. |
| [`support.html`](support.html) | FAQ. Used as the **Support URL** in App Store Connect. |
| [`privacy.html`](privacy.html) | Privacy policy. Used as the **Privacy Policy URL** in App Store Connect, and linked from the in-app paywall. |

Terms of use are Apple's
[standard licence agreement](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/),
linked directly rather than mirrored here, so it can never go stale.

All pages are self-contained: no build step, no dependencies. Edit the HTML
and push, and GitHub Pages redeploys.

The app source lives in a separate, private repository.
